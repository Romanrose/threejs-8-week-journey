# Three.js 八周学习旅程

这是我的 HTML、CSS、JavaScript、Three.js、Blender 和创意编程学习仓库。目标不是复制某一个人的作品，而是通过拆解、复刻和改造，逐渐建立自己的互动网页与 3D 创作能力。

## 当前进度

- [ ] 第 1 周：HTML、CSS、JavaScript 基础
- [ ] 第 2 周：Three.js 场景、相机、灯光
- [ ] 第 3 周：Blender 低模建模和 GLB 导出
- [ ] 第 4 周：加载模型、鼠标交互、镜头控制
- [ ] 第 5 周：GSAP 动画和页面滚动
- [ ] 第 6 周：完成一个房间式作品
- [ ] 第 7 周：加入自己的主题、音乐、文字和交互
- [ ] 第 8 周：部署到网上并写 README

## 开始运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可查看项目。

## 学习方法

每周遵循四步：

1. 运行并观察参考作品。
2. 跟着教程完成一次。
3. 关闭教程，凭理解重写关键部分。
4. 做一个自己的变体，并在对应的 `weeks/week-xx/README.md` 中记录。

## 八周安排

| 周次 | 学习重点 | 主要产出 |
