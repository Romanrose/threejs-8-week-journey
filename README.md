# Three.js 八周学习旅程

这是我的 Three.js、Blender 和创意编程学习仓库。目标不是复制某一个人的作品，而是通过拆解、复刻和改造，逐渐建立自己的 3D 网页创作能力。

## 当前进度

- [x] 第 1 周：认识 Three.js 场景
- [ ] 第 2 周：Blender 低模建模与 GLB 导出
- [ ] 第 3 周：加载模型与搭建 3D 房间
- [ ] 第 4 周：鼠标交互与 Raycaster
- [ ] 第 5 周：GSAP、滚动与镜头动画
- [ ] 第 6 周：完成一个房间式作品
- [ ] 第 7 周：加入个人主题和情绪设计
- [ ] 第 8 周：部署、复盘与作品发布

## 开始运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可查看项目。

## 学习方法

每周遵循四步：

1. 运行并观察参考作品。
2. 跟着教程完成一次。
3. 关闭教程，凭理解重写关键部分。
4. 做一个自己的变体，并在对应的 `weeks/week-xx/README.md` 中记录。
