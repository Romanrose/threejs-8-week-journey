# 第 1 周：HTML、CSS、JavaScript 基础

## 本周目标

- 用 HTML 组织语义化页面结构
- 用 CSS 完成布局、颜色、字体、响应式设计和简单动画
- 用 JavaScript 选择元素、监听事件并更新页面内容
- 理解浏览器开发者工具和基本的 Git 提交流程

## 本周产出

一个有标题、说明、按钮和交互反馈的个人主题单页。当前仓库首页就是本周练习的起点。
